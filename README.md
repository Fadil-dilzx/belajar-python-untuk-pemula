## 🛠️ Cara Menjalankan Kode di Komputer Lokal

Jika Anda ingin mencoba menjalankan skrip Python yang ada di repositori ini, ikuti langkah berikut:

1. **Pastikan Python sudah terinstal** (Minimal Python versi 3.x). Periksa dengan perintah:
   ```bash
   python --version
   ```
2. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Fadil-dilzx/belajar-python-untuk-pemula.git
   ```
3. **Masuk ke folder materi dan jalankan file `.py`:**
   ```bash
   cd 01-Dasar
   python halo_dunia.py
   ```
